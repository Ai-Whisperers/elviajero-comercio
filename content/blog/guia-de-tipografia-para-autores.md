# Guía de tipografía para autores
La tipografía es un elemento crucial en el diseño de una portada de libro. Aquí te presento algunos consejos para elegir la tipografía adecuada para tu libro:
1. Elige una fuente clara y legible
2. Utiliza tamaños de fuente coherentes
3. Asegúrate de que la fuente sea consistente en todo el libro
4. Utiliza negritas y cursivas para resaltar textos importantes
5. Asegúrate de que la fuente sea compatible con diferentes dispositivos

Para obtener más información y obtener ayuda para crear una portada de libro atractiva, no dudes en contactar a Dayah LitWorks.
