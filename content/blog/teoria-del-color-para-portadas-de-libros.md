# Teoría del color para portadas de libros
La teoría del color es fundamental para crear una portada de libro atractiva. Aquí te presento algunos consejos para elegir los colores adecuados para tu libro:
1. Elige colores que reflejen el género y el tono del libro
2. Utiliza colores que se complementen entre sí
3. Asegúrate de que los colores sean coherentes en todo el libro
4. Utiliza colores para resaltar textos importantes
5. Asegúrate de que los colores sean compatibles con diferentes dispositivos
